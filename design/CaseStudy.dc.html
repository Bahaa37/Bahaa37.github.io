Windoor Wizard Builder

A multi-tenant SaaS for Egyptian UPVC workshops, merging a commercial quoting platform with a cutting-optimisation engine verified against a real shop floor.

The problem

Workshops run on WhatsApp, Excel, and paper. Generic ERP does not help because it does not model the domain — no frame deduction registry, no bar nesting, no glass area or steel reinforcement. A workshop running generic software still does the hard part by hand.

The decision that shaped it

Lengths are stored as exact integer tenths of a millimetre, not decimals. The shop cuts half-millimetres — 44 of 195 verified rows — and a rounded cut list produces a window that does not fit. The type exposes no decimal factory, so rounding cannot enter the model at all.

Millimetres.cs WWB.Fabrication 
// There is deliberately NO decimal factory: a decimal entry point would invite
// rounding (Math.Round(483.5) == 484), destroying the very half-millimetre
// this type exists to preserve.
public readonly record struct Millimetres
{
    public int Tenths { get; }

    public static Millimetres FromTenths(int tenths) => new(tenths);
    public static Millimetres FromMm(int wholeMm)   => new(wholeMm * 10);
}
